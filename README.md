# ion-concentration-app-frontend

Фронтенд для лабораторных по РИП. Тема — растворы электролитов (кислоты, щёлочи, соли):
их можно листать лентой и искать по молярной концентрации. Бэкенд (REST API на NestJS) лежит в
[ion-concentration-app-backend](https://github.com/locos1k/ion-concentration-app-backend).

В этой ветке (ЛР5) базовое SPA на **React**, **TypeScript** и **Vite** с компонентами **React-Bootstrap**
и роутингом **React Router**. Работает только на mock-данных: без бэкенда, БД и MinIO,
запросов к API нет. Redux и `React.Context` не используются. Интерфейс рассчитан на вертикальный экран
телефона: на компьютере приложение показывается узкой колонкой (375 px) по центру.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`. Другие команды:

- `npm run build` — проверка типов и сборка в `dist/`
- `npm run lint` — проверка кода (oxlint)

## Страницы

В нижнем меню четыре пункта: **Лента**, **Добавление**, **Плитка**, **Вход**. Работают два — Лента и Плитка.
«Добавление» и «Вход» пока недоступны (приглушены и не нажимаются), страницы для них появятся в следующих ЛР.
Активный пункт подсвечивается. Любой неизвестный адрес ведёт на ленту.

| Страница | Адрес | Описание |
|---|---|---|
| Лента | `/solutions` | Первый раствор из списка |
| Лента | `/solutions/:id` | Раствор с заданным `id` |
| Плитка | `/solutions/list` | Каталог растворов с фильтром |

### Лента

Видео раствора на весь экран (автозапуск, без звука, по кругу), поверх него:

- **Название** и **описание**. Длинное описание обрезано, кнопка **Ещё** раскрывает его целиком, **Свернуть** сворачивает обратно.
- **Лайки** — иконка и число лайков, только показ (поставить лайк пока нельзя).
- **Следующий** — кнопка со стрелкой, открывает следующий раствор из списка. После последнего снова первый.
- **pH** — круглый бейдж с водородным показателем.
- **моль/л** — круглый бейдж с молярной концентрацией.

Если раствор с таким `id` не найден, показывается «Раствор не найден».

### Плитка

- **Фильтр по молярной концентрации** — два ползунка: минимум и максимум, от 0 до 0,25 моль/л с шагом 0,01.
  Подпись «от … до …» меняется при перетаскивании, а список обновляется только по кнопке **Найти**.
  Если минимум больше максимума, ничего не найдётся: «Ничего не найдено».
- **Карточки растворов** в два столбца: картинка, название, количество лайков, молярная концентрация.
  Клик по карточке открывает ленту с этого раствора.

Лента листается по тому же списку, который сейчас показан на плитке (после фильтра — только по найденным растворам).
Если вернуться на плитку, фильтр сбрасывается.

### Изображение и видео по умолчанию

Если у раствора нет картинки или видео (поле пустое) либо файл по ссылке не загрузился, показываются
`public/img/default-solution.PNG` и `public/img/default-solution.mp4`. Это работает и на плитке, и в ленте.
Для проверки в mock есть «Фосфорная кислота» и «Карбонат натрия» без картинок и видео.

## Данные

Все растворы берутся из массива `SOLUTIONS_MOCK` в `src/modules/solutions.mock.ts` (7 штук).
Поля растворов повторяют ответ API бэкенда: `id`, `substanceName`, `description`, `molarConcentration`,
`ph`, `imageUrl`, `videoUrl`, `likesCount`, `isLiked`, `isCreator`. Картинки и видео лежат в `public/media/`.

## Что где лежит

- `src/main.tsx` — точка входа, подключает стили Bootstrap и `solutions.css`
- `src/SolutionsApp.tsx` — роутинг
- `src/SolutionsLayout.tsx` — общая оболочка: хранит список растворов `cards` и передаёт его страницам через `Outlet context`, рисует меню
- `src/Routes.ts` — адреса и подписи пунктов меню
- `src/pages/` — страницы: `SolutionsFeedPage.tsx` (лента), `SolutionsGridPage.tsx` (плитка)
- `src/components/` — компоненты: `SolutionCard`, `SolutionsFilter`, `SolutionDescription`, `SolutionVideo`, `SolutionsNavbar`
- `src/modules/` — модель `Solution`, mock-данные, фильтрация по концентрации, пути к файлам по умолчанию
- `src/solutions.css` — стили приложения
- `public/media/` — картинки и видео растворов, `public/img/` — иконка лайка и файлы по умолчанию
